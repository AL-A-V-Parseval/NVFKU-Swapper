# NVFKU-Swapper v0.1.1

Linux x86_64 maintenance release combining the rollback/integrity review fixes and the navigation/layout fixes. Both the Python engine and Flutter frontend are versioned **0.1.1**.

## Highlights / 更新内容

- **UI navigation:** keep the sidebar visible at desktop tiled widths (760px and above), stretch it from the top, and preserve scrolling at short heights. Narrow windows retain an explicit, localized menu button and a drawer that closes after navigation.
- **Home layout:** fill the available drop-panel width with horizontal padding, avoiding clipped Chinese hints. Clean Release builds include the menu glyph; the built font was inspected rather than relying only on build success.
- **Safer install/rollback:** serialize game transactions, compensate interrupted installs, preserve actionable incomplete journals, check backup and post-image integrity, and refuse unsafe restoration rather than reporting false success.
- **Component/model integrity:** version/URL-aware component caches, staged atomic publication, size/digest receipts, and invalid-model ZIP eviction for an explicit retry. Local receipts are not upstream authentication.
- **Reliability:** ordered settings writes, usable engine startup errors/retry, bounded Steam/model discovery, lazy game layout and bounded cover decoding.
- **Release tooling:** unique immutable build identities, source/runtime manifests, SHA256SUMS, declared interpreter/native ABI constraints, model-free packaging checks and isolated CLI smoke verification.
- **Regression coverage:** full-shell keyboard/layout/appearance tests, concurrency and failure-injection tests, and Python 3.9/3.14 + Flutter/Linux packaging CI configuration. The synthetic install-failure test no longer depends on whether the host Steam client is running; production Steam safety checks remain unchanged.

本版修复侧边栏消失/居中、窄窗口菜单缺失和首页拖放提示裁切，同时包含此前审查的备份恢复、事务回滚、组件缓存、设置并发与扫描改进。

## Downloads / 下载

Use the attached **tar.gz**, **amd64 deb**, or **x86_64 AppImage**, and verify the download against **SHA256SUMS**. All three formats are **model-free**: NVIDIA's proprietary neural model is not redistributed. See [model/licensing notices](../../THIRD_PARTY_NOTICES.md) and the [README](../../README.md) for setup.

Runtime requires Python **3.9+** and the host GTK3 stack; the exact measured glibc/libstdc++ requirements are in the bundled `RELEASE.json` (and Debian control metadata). These artifacts are built on the local Linux host, not represented as Ubuntu-built binaries; CI artifacts are separate. Matching an ABI floor does not prove distribution compatibility.

## Limits / 已知限制

This remains a community-route tool, not an NVIDIA release or a general guarantee of DLSS/game/driver compatibility. Native/FUSE AppImage startup, actual Debian installation, clean-distribution GUI acceptance, screen readers, real-game compatibility and GPU frame times were not newly validated for this release. The GUI checks used the locally rebuilt release bundle; extraction/CLI checks do not substitute for native package startup.

Back up game files and exit Steam before operations that write launch options. Legacy journals may lack modern integrity metadata; local cache receipts do not authenticate publishers. Journal/receipt writes are not a power-loss/fsync durability guarantee. See [release gates and remaining manual checks](../release-workflow.md).

The older dated review reports describe their own snapshots and test counts; their “not committed/published” and “old packages” statements are historical, not the state of v0.1.1.
